# Navod Portfolio

A redesigned professional portfolio for Navod Kiriwaththuduwa.

## Positioning

**Engineering · Leadership · Impact**

The site is designed as a professional portfolio rather than a traditional online CV. It uses the existing `NavodK` repository as the source for verified profile information, reports and media while introducing a new information hierarchy and visual system.

## Structure

- Hero and professional positioning
- Engineering / Leadership / Impact pillars
- Professional journey timeline
- Featured projects with filters
- Leadership highlights
- Education
- Reports and portfolio evidence
- Contact section

## Files

- `index.html` — page content and semantic structure
- `styles.css` — responsive visual system and light/dark themes
- `script.js` — navigation, theme, filters and reveal interactions
